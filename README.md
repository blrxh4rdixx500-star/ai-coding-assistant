# مشروع الذكاء الاصطناعي للبرمجة (Fine-Tuning Script)

هذا المشروع يوفر سكريبتات Python جاهزة للبدء في تدريب نموذج لغة كبير (LLM) متخصص في البرمجة، باستخدام تقنية **الضبط الدقيق (Fine-Tuning)** على بياناتك الضخمة (300 جيجابايت+).

الاستراتيجية المتبعة هي استخدام تقنية **QLoRA** لتقليل متطلبات الذاكرة الرسومية (VRAM) واستخدام **Hugging Face Datasets Streaming** للتعامل مع حجم البيانات الهائل دون تحميله بالكامل في الذاكرة.

## 1. المتطلبات الأساسية

لنجاح عملية التدريب، يجب توفير بيئة عمل مناسبة:

1.  **جهاز حوسبة قوي (GPU)**: يفضل استخدام بطاقة رسومية قوية (مثل NVIDIA A100 أو H100) بذاكرة VRAM لا تقل عن 24 جيجابايت.
2.  **نظام تشغيل Linux** (موصى به).
3.  **Python 3.10+**.
4.  **تثبيت المكتبات المطلوبة**:

```bash
pip install torch transformers datasets peft accelerate bitsandbytes
```

## 2. إعداد البيانات (300GB+)

يجب أن تكون بياناتك منظمة بالتنسيق التالي:

1.  **إنشاء مجلد البيانات**: قم بإنشاء مجلد باسم `raw_data` في نفس مسار السكريبتات.
    ```bash
    mkdir /home/ubuntu/raw_data
    ```
2.  **تنسيق الملفات**: يجب أن تكون جميع بياناتك (الـ 300 جيجابايت) في شكل ملفات **JSONL** (كل سطر هو كائن JSON مستقل).
3.  **هيكلية البيانات**: يجب أن يحتوي كل كائن JSON على مفتاحين أساسيين:
    *   `instruction`: السؤال أو المهمة البرمجية (مثلاً: "اكتب دالة بايثون لفرز قائمة").
    *   `code_solution`: الحل البرمجي للمهمة.

**مثال لسطر واحد في ملف JSONL:**
```json
{"instruction": "Write a function to calculate the Fibonacci sequence up to n.", "code_solution": "def fibonacci(n):\n    a, b = 0, 1\n    while a < n:\n        print(a, end=' ')\n        a, b = b, a+b"}
```

## 3. سكريبت معالجة البيانات (`data_preparation_script.py`)

هذا السكريبت يقوم بما يلي:
*   يقرأ ملفات JSONL من مجلد `/home/ubuntu/raw_data`.
*   يستخدم وضع التدفق (`streaming=True`) لضمان عدم استهلاك الذاكرة.
*   يقوم بتنسيق البيانات إلى شكل مناسب لتدريب النموذج (تحويل `instruction` و `code_solution` إلى نص واحد).

**كيفية التشغيل (للتأكد من التنسيق):**
```bash
python3 data_preparation_script.py
```
*ملاحظة: السكريبت يحتوي على جزء تجريبي يقوم بإنشاء ملف وهمي صغير لاختبار وظيفة التدفق والتنسيق.*

## 4. سكريبت التدريب (`fine_tuning_script.py`)

هذا هو السكريبت الرئيسي الذي يقوم بعملية الضبط الدقيق:

*   **النموذج الأساسي**: يستخدم `deepseek-ai/deepseek-coder-7b-base` (يمكن تغييره).
*   **التقنية**: يستخدم QLoRA لتدريب فعال بذاكرة قليلة.
*   **البيانات**: يستخدم `IterableDataset` لمعالجة البيانات الضخمة المتدفقة.

**كيفية التشغيل (الخطوة الحاسمة):**

للاستفادة القصوى من موارد جهازك (خاصة إذا كان لديك أكثر من GPU)، يجب تشغيل السكريبت باستخدام أداة `accelerate`:

```bash
# 1. قم بتهيئة Accelerate (يجب القيام بها مرة واحدة)
accelerate config

# 2. قم بتشغيل سكريبت التدريب
accelerate launch fine_tuning_script.py
```

**ملاحظة هامة:** عملية التدريب على 300 جيجابايت من البيانات هي عملية طويلة جداً وقد تستغرق أياماً أو أسابيع حسب قوة جهازك.

## 5. مخرجات المشروع

بعد الانتهاء من التدريب، سيتم حفظ النموذج المدرب في مجلد `./deepseek_coder_finetuned`. يمكنك استخدام هذا النموذج الجديد لإنشاء ذكاء اصطناعي ذكي للبرمجة.
